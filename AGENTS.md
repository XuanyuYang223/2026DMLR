# Repository language

Use English for repository content, including documentation, reports, code comments,
generated prose, figure labels, and textual result classifications. Conversation
with the user can follow the user's preferred language.

When translating completed experiments, preserve numerical results, data, model
weights, and frozen scientific records. Record documentation revisions separately
so archived hashes remain traceable. Update report generators as well as their
generated documents to keep future output in English.
