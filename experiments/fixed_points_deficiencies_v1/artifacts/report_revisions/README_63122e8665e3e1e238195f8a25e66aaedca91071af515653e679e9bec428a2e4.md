# Fixed-points deficiencies confirmation

This independent case asks whether adding `deficiencies` improves `fixed_points` transfer more than adding the prespecified `right_to_left_maxima` comparator, with the common background `descents`, `successions`, and `left_to_right_maxima` held fixed. It preserves pilot v5 and task-count v1/v2 as historical hypothesis sources, including their failed confirmations and limitations.

**Current status:** scientific protocol frozen; verified data, initialization, mathematics, and wiring; formal training in progress. Tests are withheld until all development selections freeze. No final scientific claim is available yet. All work remains local on `experiments/fixed-points-deficiencies-v1`; no upload or publication is part of this task.

## Fixed scope

- Eight new paired units; P/D/T/U fourth-source candidates are peaks/deficiencies/anti_fixed_points/right_to_left_maxima, plus shared scratch baseline A.
- Legacy v5 one-line n=10 Transformer; 32 source models at 4,800 updates each.
- Nested target subsets of 256, 512, and 1,024; 800-update full-parameter adaptation and the same three development-selected learning rates for every route. There are 360 candidate runs and 120 selected results.
- Additional target supervision: 1,024 labeled development examples per unit. This is not a claim of only 256 total target labels.
- Unique primary contrast: within-unit `S_D - S_U`, where `S = .25*A256 + .5*A512 + .25*A1024`; eight-unit paired 95% t interval with df=7.
- Complete generated answer plus EOS is the main accuracy. The legacy answer-token metric is retained separately.
- No new target, composition, budget, architecture, or mechanistic intervention after this scope.

## Reproduce

Run from the repository root with its CUDA-enabled Python environment. The commands in [EXECUTION_LOG.md](EXECUTION_LOG.md) generate or verify the isolated pools, prepare new initializations, freeze the protocol, train the complete inventory, freeze development choices, and only then generate and evaluate tests. Existing bound completed runs are verified and skipped; interrupted runs restore their own optimizer and RNG states.

After all test records exist:

```powershell
.venv/Scripts/python.exe experiments/fixed_points_deficiencies_v1/train.py aggregate
.venv/Scripts/python.exe experiments/fixed_points_deficiencies_v1/final_check.py
.venv/Scripts/python.exe experiments/fixed_points_deficiencies_v1/analysis.py
.venv/Scripts/python.exe experiments/fixed_points_deficiencies_v1/independent_recompute.py
```

Do not modify frozen source files to resume a run. Do not generate a new test set to replace an unfavorable outcome. If an asset is missing, report it rather than weakening isolation or substituting a seed.
