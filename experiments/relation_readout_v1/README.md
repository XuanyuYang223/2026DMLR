# Registered relation readout v1

Inference-only evaluation of four fixed registered relations on existing task_count_v2 checkpoints. Read REPORT.md for results and limitations. All new artifacts are isolated here; historical hashes are references, never rebound.

`executor.query_inputs(edge, permutation)` applies the registered transforms and returns task, input and parameter triples. `executor.reconstruct(edge, permutation, provider)` accepts a replaceable callable `provider(task, permutation, params)` returning an integer or None. `apply_answers` executes the registry's allowlisted answer-map tree and propagates missing answers. It never calls a task oracle. The model provider in run.py uses the unchanged full-answer greedy generator and precision rules; oracle labels are used only for encoding gold suffixes, formula verification and scoring, never as generated answers. Prompt generation slices off gold suffixes before every model forward.

Run from repository root with `.venv/Scripts/python.exe experiments/relation_readout_v1/run.py freeze`, then `run.py evaluate`. Run `audit.py` to check internal checkpoint provenance. Run `summarize.py` once to create repeat-level tables, then `accounting.py` to join measured physical query blocks, then `summarize.py` to include accounting in the final report. Use the same Python executable and directory prefix for each script. Freeze is intentionally single-use. Do not rerun evaluation into existing output files. The frozen JSON binds executor and inference source code before any formal predictions. The summary generator is separate from inference and may be improved without changing routes or predictions; DOCUMENTATION_REVISION.json records its original and revised hashes.

Inventory: checkpoints.json (identity, archived hash, source set, selection and completion records); routes.json (full registered query and mapping definitions); availability.json (NA conditions); data_manifest.json (new inputs and historical exclusion bindings); FROZEN_PROTOCOL.json (seeds, statistics, failure rules and fixed budget). Missing or hash-mismatched checkpoints are never replaced or retrained. Figures and all report text are English.
