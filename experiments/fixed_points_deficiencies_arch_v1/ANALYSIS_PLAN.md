# Analysis registration

`stats_plan.json` is a byte-identical copy of the original fixed-points confirmation's statistical plan. Its score, sole primary contrast, secondary contrasts, endpoint diagnostic, full-answer metric, paired eight-unit summary and t interval remain unchanged. It is applied only to the new units in `plan.py` and never pooled with old observations.

The GRU gate is a separate endpoint-only development decision under its own committed protocol. Report both single-task endpoint accuracies and the deterministic model choice, without counting gate tasks or checkpoints as confirmation repeats. Preserve a failed gate and identify a Transformer fallback as a depth change rather than a second architecture family.

All formal model selection precedes test generation. Independent source-only reconstruction checks pairing, initializations, complete checkpoint loading, target-only row reset, fresh optimizers, source/target exposure streams, selection ordering and data/checkpoint hashes. After the unified test evaluation, independently reconstruct each accuracy and primary paired statistic from saved per-example predictions and compare them with the analysis tables. No additional model forward is used to repair a statistic.

Report D-U alongside D-A, P-A, T-A and U-A so comparison-condition negative transfer cannot be presented as a large gain over scratch. Report all prespecified secondary contrasts irrespective of sign. Interpret an interval including zero as inconclusive; a nonpositive result does not trigger an extension or source replacement. Source-task learning and answer-distribution differences remain descriptive confounds, not causal mechanism evidence.

Every report must state the selected model, vocabulary 188, n=10, eight new units, all three target training sizes and the additional labeled development set. Checkpoint files remain local. Published numerical tables and reports retain their own protocol identity and are not merged with platform calibration, task-count or readout experiments.
